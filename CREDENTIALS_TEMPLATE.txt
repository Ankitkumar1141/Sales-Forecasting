SECTION 2: POSTGRESQL DATABASE
--------------------------------------------------------------

The pipeline uses PostgreSQL instead of MongoDB because the data
is fully relational (store_nbr FK, date-keyed rows, SQL JOINs).

Recommended FREE hosting options:
  • Supabase  → https://supabase.com        (500 MB free)
  • Neon      → https://neon.tech           (512 MB free, serverless)
  • Railway   → https://railway.app         (500 MB free)
  • Local     → Install PostgreSQL locally for development

STEP 1: Create a PostgreSQL database on one of the platforms above.

STEP 2: Run the schema script to create the tables:
  psql -h <HOST> -U <USER> -d <DATABASE> -f db/schema.sql
  (Or paste db/schema.sql into the platform's SQL editor)

STEP 3: Load your CSV data using the instructions in db/seed_from_csv.sql

STEP 4: Fill in secrets.env with the values below:

  PG_HOST     = YOUR_POSTGRES_HOST
                (e.g. db.xxxxxxxx.supabase.co   for Supabase)
                (e.g. ep-xxxxxx.us-east-2.aws.neon.tech  for Neon)
                (e.g. localhost  for local dev)

  PG_PORT     = 5432          (default, change if needed)

  PG_DATABASE = store_sales   (or whatever name you chose)

  PG_USER     = YOUR_POSTGRES_USERNAME

  PG_PASSWORD = YOUR_POSTGRES_PASSWORD

NOTE: For local development without SSL, also change sslmode
      in config/config.yaml from "require" to "disable",
      OR set a PG_SSLMODE=disable override in secrets.env
      (and add it to the _get_engine() method in data_ingestion.py).

SECTION 7: DATABASE TABLE REFERENCE
--------------------------------------------------------------

The pipeline expects these 4 tables in your PostgreSQL database:

  Table name    | Source CSV                    | Key columns
  ------------- | ----------------------------- | ---------------------------------
  store_sales   | train.csv (Kaggle dataset)    | id, date, store_nbr, family, sales, onpromotion
  oil_prices    | oil.csv                       | date, dcoilwtico
  stores        | stores.csv                    | store_nbr, city, state, type, cluster
  holidays      | holidays_events.csv           | date, type, locale, locale_name, description, transferred

See db/schema.sql for the full CREATE TABLE definitions.
